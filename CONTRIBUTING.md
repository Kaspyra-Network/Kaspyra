# Contributing

We welcome focused research, reproducible experiments, documentation corrections and security analysis.

1. Open an issue describing the problem, hypothesis and measurable acceptance criteria.
2. Keep experiments deterministic where possible; include seeds, commands and raw result provenance.
3. Clearly label simulations, assumptions and unverified proposals.
4. Submit small pull requests with tests and a short explanation of tradeoffs.
5. Do not include credentials, private keys, personal information, or unauthorized network probes.
6. Do not imply any satellite-provider endorsement or partnership.

Contributors should not treat open issues or draft whitepapers as production commitments.
