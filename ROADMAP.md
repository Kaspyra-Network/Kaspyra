# KASPYRA Research Roadmap

This roadmap describes **research gates**, not launch dates or guaranteed deliveries.

| Phase | Objective | Exit evidence |
|---|---|---|
| Research 001 | Compare transport overlay, existing-stack integration and new L1 | Written tradeoff analysis and threat model |
| Experiment 001 | Deterministic local disruption simulation | Reproducible test suite, seeds and limitations |
| Experiment 002 | Authorized satellite ground-terminal relay | Real measurements vs terrestrial baseline |
| Experiment 003 | Hybrid connectivity and failover | Repeated outage tests and failure analysis |
| Experiment 004 | Offline signing and honest transaction status | End-to-end test with independently verified receipts |
| Experiment 005 | Commercial feasibility | Customer discovery and credible cost model |
| Research 002 | Asynchronous interplanetary settlement | Formal cross-domain threat model and feasibility study |

**Current state:** documentation and initial local message-delivery simulation. No live satellite trials or blockchain deployments.
